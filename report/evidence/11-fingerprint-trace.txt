Scheme change (external-review driven):
  - marking identity: 128-bit CSPRNG token per (share, recipient), UNIQUE in DB
  - codeword: HMAC-SHA-256 keyed by the full token bytes, counter-mode blocks
    (8 big-endian uint32 words per block, 64 blocks -> 512 Bernoulli(p_i) draws)
  - token travels ONLY in the URL fragment (#<R>:<token>); the ?r= query parameter
    was removed entirely
  - tracer scores only registered tokens; unregistered identities are rejected;
    legacy evidence requires the explicit --legacy flag or the CS1 trailer format
